# Worked Examples

Walkthroughs of complete ProofFrog proofs from the `examples/` directory, organized by complexity. Each example introduces ideas that the next one builds on.

If you have just finished [Tutorial Part 2]({% link manual/tutorial-2-otp-ots.md %}), start at the top.

## Examples

1. [Chained Encryption]({% link manual/worked-examples/chained-encryption.md %}) — first reduction proof; introduces the four-step reduction pattern in narrative form.
2. [KEM-DEM CPA]({% link manual/worked-examples/kemdem-cpa.md %}) — multi-primitive proof exercising three reductions, two of them to the same assumption in opposite directions; the graduation piece.

More examples will be added over time. Each new example is one file plus one line in this list.
